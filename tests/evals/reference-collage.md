# Evals: reference-collage

Run each prompt in a fresh session with the library installed and a config set. Tick each check, then score with the rubric in BETA.md.

## Case 1
**Prompt:** Find references for a fintech onboarding flow for first-time investors in India. Calm, trust heavy, not dark mode.

**Checks**
- [ ] Writes a 3 line brief before searching
- [ ] Plans 6 to 10 queries across literal, niche, structure and mood
- [ ] Gathers 40+ candidates from at least 2 sources
- [ ] Builds and reads a contact sheet before scoring
- [ ] Keeps 10 to 16 picks with borrow, why, laws, avoid
- [ ] Rejected list has reasons
- [ ] Writes board.canvas and board.md with measured palette
- [ ] Credits every image with its source link

## Case 2
**Prompt:** more like 3 and 7, drop anything with gradients

**Checks**
- [ ] Moves 3 and 7 to Top picks
- [ ] Adds gradient to disliked and removes matching cards
- [ ] Runs new queries from 3 and 7 and adds up to 6 cards to Maybe
- [ ] Updates liked and disliked in board.md
