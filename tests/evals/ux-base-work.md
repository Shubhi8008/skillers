# Evals: ux-base-work

Run each prompt in a fresh session with the library installed and a config set. Tick each check, then score with the rubric in BETA.md.

## Case 1
**Prompt:** Pricing page for a B2B design tool with 3 plans

**Checks**
- [ ] Names the goal in the first line
- [ ] Problem statement has who, goal, pain, cause, impact
- [ ] 3 grayscale options with numbered markers tied to laws
- [ ] Rule pass done, broken rules flagged
- [ ] SEO block present
- [ ] Decision log with evidence or assumption plus test
- [ ] One recommendation and one first test

## Case 2
**Prompt:** Signup flow for a habit tracking app, mobile first

**Checks**
- [ ] Asks at most 2 questions, only if goal or page type missing
- [ ] Forms over 6 fields split into steps
- [ ] Mobile primary action in thumb reach
