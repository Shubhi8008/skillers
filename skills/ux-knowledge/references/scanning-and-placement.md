# Scanning and placement

## How people scan (NN/g eye tracking, Pernice 2017)
- **F-pattern**: wide read across the top, shorter read lower, then down the left edge. Default when nothing guides the eye.
- **Layer cake**: reads headings, skips body. Best pattern to design for.
- **Spotted**: hunts for one thing (number, link, word shape).
- **Marking**: eyes stay fixed while scrolling, common on mobile.
- **Bypassing**: skips repeated first words in lists.
- **Commitment**: reads everything. Rare. Do not plan for it.

Causes of F-pattern: walls of text, low motivation, weak information scent.

## Where attention goes (NN/g, Fessenden 2018)
| Study | First screen | Below |
|---|---|---|
| 2010 | 80% of viewing time | 20% |
| 2018 | 57% | 43% |
2018: 74% of time in first two screens, 81% in first three.

## Placement rules for the skill
1. Value proposition and primary CTA in the first screen.
2. First two paragraphs carry the main point.
3. Headings start with the most informative words.
4. Group related blocks with a border or background (common region).
5. Bold key phrases. Use lists for steps.
6. Descriptive link text, never "click here".
7. No false floors. Let the next section peek above the fold.
8. Repeat the CTA after each major proof block and at the end (serial position).
9. Left column gets the strongest labels (F-pattern).
