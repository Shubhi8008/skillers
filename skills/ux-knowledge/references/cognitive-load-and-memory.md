# Cognitive load and memory

## Definition
Cognitive load is the mental effort needed to use an interface. Working memory is small. When an interface asks for more than it can hold, people slow down, miss things and make errors.

## Three loads (Sweller and colleagues)
- **Intrinsic**: the difficulty of the task itself. Cannot remove, only sequence it well.
- **Extraneous**: effort spent on things that do not help the task (decorative fonts, clutter, hunting for controls). This is the designer's job to cut.
- **Germane**: effort that builds understanding. Make room for it by cutting extraneous load.

Timeline: Miller 1956 (7 ± 2) · Sweller 1988 cognitive load theory in Cognitive Science · Chandler and Sweller 1991 intrinsic vs extraneous · Paas and van Merriënboer 1994 germane · Cowan 2001 revises capacity to about 4 chunks.

## Design moves (NN/g, Whitenton 2013)
1. Chunk content into small groups. Keep responses fast.
2. Cut visual clutter: redundant links, irrelevant images, decorative type.
3. Reuse familiar layouts and labels so there is less to learn.
4. Offload work: show pictures instead of text, redisplay earlier answers, set smart defaults.

## Checks the skill runs
- Count distinct choices on the first screen. Above 7, group or cut.
- Count font sizes and colors. More than 4 sizes or 3 accents is noise.
- Any screen that needs info from a previous screen must show it again.
- Long forms: split into steps of 3 to 5 fields with a progress indicator.

Sources: https://www.nngroup.com/articles/minimize-cognitive-load/ · Sweller 1988, Cognitive Science 12(2) · Cowan 2001
