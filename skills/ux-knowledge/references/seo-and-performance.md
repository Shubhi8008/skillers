# SEO and performance

## What Google says to do (SEO Starter Guide)
- Unique, clear title per page.
- Headings that break content into sections.
- Readable URLs with real words, topics grouped in folders.
- One URL per piece of content, canonical for duplicates.
- Descriptive anchor text for links.
- Sharp images near related text, with descriptive alt text.
- Short unique meta description.
- Original, up to date, helpful writing. Use the words readers search with.
- Ads and interstitials must not block content.
- Google must load the same CSS and JS the user gets.

## What Google says does not matter
Meta keywords tag. Keyword stuffing (against spam policy). Keywords in domain. Exact word count. Heading order or count. E-E-A-T is not a direct ranking factor.

## Core Web Vitals (good thresholds, 75th percentile)
- LCP (loading) 2.5 s or less
- INP (interaction) 200 ms or less
- CLS (layout shift) 0.1 or less

## What this means for a wireframe
- Every wireframe ships an SEO block: page title, H1, H2 outline, URL slug, meta description, alt text plan.
- One H1 that matches the main search intent in plain words.
- Hero image sized up front to avoid layout shift. Text in HTML, not baked into images.
- No full screen popups on load.

Sources: https://developers.google.com/search/docs/fundamentals/seo-starter-guide · https://web.dev/articles/vitals
